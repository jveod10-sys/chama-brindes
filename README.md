# Chama Brindes

Site em HTML, CSS e JavaScript, com catálogo de produtos e orçamento pelo WhatsApp.

Abra `index.html` no navegador para visualizar localmente. O catálogo carrega
`data/catalogo.js` e usa imagens de `assets/images/catalogo/`. Preserve essa
estrutura ao publicar o projeto.

- 15.256 produtos com nomes e identificadores preservados.
- 31.260 imagens válidas integradas ao catálogo.
- Pesquisa, filtros por categoria, galerias e carregamento progressivo.
- WhatsApp: `5511947582966`, incluindo o produto escolhido na mensagem.

Os originais ocupam aproximadamente 3,33 GB. Os arquivos temporários de navegador
e o cache da coleta não fazem parte do repositório.

Há 150 produtos sem foto na origem e 4 arquivos de imagem inválidos, registrados
em `data/RELATORIO-IMPORTACAO.md`. Nomes ambíguos permanecem em Outros brindes;
as categorias organizadas pelo nome e os itens para revisão estão documentados
em `data/categorias-relatorio.json`.

Consulte `scripts/LEIA-ME.md` para retomar ou atualizar a importação e executar
as verificações. A coleta cobre toda a listagem pública; galerias exclusivas de
páginas individuais de fornecedores não foram verificadas exaustivamente.
